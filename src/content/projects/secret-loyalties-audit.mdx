tldr: 'An audit of three model organisms secretly loyal to some principal. The point was to treat elicitation as inference: the unit is an (entity, template) cell, never the rollout; clustered bootstrap intervals; a true null organism to keep us honest. Cued elicitation named the wrong principal by two orders of magnitude; unconditional sampling with no prompt found the right one in nine GPU-minutes. The report credits Claude Opus 5 as co-author, because it wrote the code and most of the text; I chose the directions, hypotheses and the statistics, and checked them.'
